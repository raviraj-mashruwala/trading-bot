# P1 Jev Tier 2 Integration Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace Tier 2 regime and sector Claude calls with Jev (~100ms vs ~5s each), and add a live regime monitor to the executor tick loop.

**Architecture:** `JevTier2Analyzer` mirrors `Tier2Analyzer`'s interface but calls JevClient instead of LLMProvider. Pipeline injects it for regime/sectors when Jev is available, keeps Claude for shortlist. `RegimeMonitor` is a small class that runs a Jev check every 5 minutes during market hours.

**Tech Stack:** Python 3.12, typesafe-sdk (optional), JevClient from P0

**Spec:** `docs/superpowers/specs/2026-10-03-p1-jev-tier2-design.md`

## Global Constraints

- JevClient from P0 (`tradingbot/core/jev_client.py`) is the only interface to Jev — all calls go through it
- Return dicts must match existing REGIME_SCHEMA and SECTOR_SCHEMA so downstream code (shortlist, backtest, Tier 3) doesn't change
- `shortlist()` stays on Claude — JevTier2 must NOT implement it
- Pipeline and executor changes must be backward-compatible: no Jev config = existing behavior
- `MarketRegime` enum values: `trending_up`, `trending_down`, `range_bound`, `volatile`, `low_vol_squeeze`

## Review Focus

1. **Regime dict missing required keys:** Downstream code (shortlist prompt, backtest regime gate) accesses `regime["regime"]`, `regime["regime_confidence"]`, `regime["sectors_in_play"]`. A missing key crashes the pipeline. Test in Task 1.
2. **Sector composite calculation produces NaN:** If Jev returns unexpected score values, 0.6×NaN + 0.4×rotation = NaN. Sorting NaN breaks ranking. Test in Task 1.
3. **Pipeline fallback when Jev fails mid-run:** Jev succeeds for regime but fails for sectors — pipeline must fall back to Claude for sectors only, not retry regime. Test in Task 2.
4. **RegimeMonitor called with stale market_data:** If market data feed is lagging, regime check uses old data. should_check must verify data freshness. Test in Task 3 (add freshness check to should_check).
5. **Concurrent regime monitor + entry evaluation in same tick:** Both use JevClient — ensure no shared state corruption. The JevClient creates a new connection per call, so this is safe by design. Verified by reading jev_client.py — no instance-level state mutated during evaluate().

```python
"""Jev-based Tier 2 analyzer: regime classification + sector scoring."""

from __future__ import annotations

import logging
from typing import Any

from tradingbot.core.jev_client import JevClient, Choice, Noul, Score

log = logging.getLogger(__name__)

SECTORS = ["banking", "it", "pharma", "auto", "metal", "fmcg", "energy", "realty", "infra"]


class JevTier2Analyzer:
    """Replace Claude Tier 2 calls for regime and sectors with Jev."""

    def __init__(self, jev_client: JevClient) -> None:
        self._jev = jev_client

    async def analyze_regime(
        self,
        nifty: float,
        banknifty: float,
        vix: float,
        nifty_5d_change: float,
        fii_5d_net: float,
        dii_5d_net: float,
        advance_decline: float,
        sector_data: dict[str, float],
    ) -> dict[str, Any] | None:
        if Choice is None:
            return None
        state = {
            "nifty_level": nifty,
            "banknifty_level": banknifty,
            "india_vix": vix,
            "nifty_5d_change_pct": nifty_5d_change,
            "fii_5d_net_crores": fii_5d_net,
            "dii_5d_net_crores": dii_5d_net,
            "advance_decline_ratio": advance_decline,
            "sector_changes": sector_data,
        }
        questions = {
            "regime": Choice(
                instructions="What is the current market regime based on the data?",
                criteria={
                    "trending_up": "Broad uptrend — rising index, healthy breadth, institutional buying",
                    "trending_down": "Broad downtrend — falling index, poor breadth, institutional selling",
                    "range_bound": "Sideways — low directional conviction, mixed signals",
                    "volatile": "High VIX, sharp intraday swings, uncertain direction",
                    "low_vol_squeeze": "Compressed volatility, low VIX, narrow range — breakout likely",
                },
            ),
            "regime_confidence_level": Score(
                instructions="How clear is the market regime signal?",
                criteria=[
                    "Low clarity — conflicting indicators, hard to classify",
                    "Some signal — leans one way but not convincing",
                    "Clear signal — most indicators agree",
                    "Very strong signal — overwhelming agreement across indicators",
                ],
            ),
            "bias": Choice(
                instructions="What is the overall directional bias?",
                criteria={
                    "bullish": "Net positive outlook — favor long trades",
                    "bearish": "Net negative outlook — favor shorts or stay defensive",
                    "neutral": "No clear directional edge",
                },
            ),
            "risk_appetite": Choice(
                instructions="What risk stance should trading take today?",
                criteria={
                    "aggressive": "Strong signals, take full position sizes",
                    "moderate": "Mixed signals, standard position sizes",
                    "defensive": "Uncertain or adverse conditions, reduce size or sit out",
                },
            ),
            "trend_strength": Score(
                instructions="How strong is the prevailing directional trend?",
                criteria=[
                    "No clear trend — choppy or flat",
                    "Weak trend — some directional bias but fragile",
                    "Moderate trend — clear direction with some counter-signals",
                    "Strong trend — broad participation, aligned indicators",
                ],
            ),
            "institutional_sentiment": Score(
                instructions="How bullish is institutional flow (FII + DII combined)?",
                criteria=[
                    "Strongly bearish — heavy net selling",
                    "Mildly bearish — net selling but not extreme",
                    "Neutral — mixed or minimal flow",
                    "Mildly bullish — net buying",
                    "Strongly bullish — heavy net buying from both",
                ],
            ),
        }

        answers = self._jev.evaluate(state=state, questions=questions)
        if answers is None:
            return None

        try:
            regime = answers["regime"].choice
            conf = answers["regime_confidence_level"].score / 3.0
            bias = answers["bias"].choice
            risk = answers["risk_appetite"].choice
            trend = answers["trend_strength"].score / 3.0
            inst = answers["institutional_sentiment"].score / 4.0

            reasoning = (
                f"jev: regime={regime}(conf={conf:.2f}), bias={bias}, "
                f"risk={risk}, trend_strength={trend:.2f}, institutional={inst:.2f}"
            )

            return {
                "regime": regime,
                "regime_confidence": round(conf, 2),
                "bias": bias,
                "key_levels": {},
                "sectors_in_play": [],
                "sectors_to_avoid": [],
                "risk_appetite": risk,
                "reasoning": reasoning,
            }
        except Exception:
            log.warning("Jev regime answer parsing failed", exc_info=True)
            return None

    async def analyze_sectors(
        self,
        regime: dict,
        sector_data: dict,
        top_stocks_by_sector: dict,
    ) -> dict[str, Any] | None:
        if Noul is None:
            return None

        state = {
            "market_regime": regime.get("regime", "unknown"),
            "sector_data": sector_data,
        }
        questions: dict[str, Any] = {}
        for sector in SECTORS:
            questions[f"{sector}_momentum"] = Score(
                instructions=f"How strong is `{sector}` sector's momentum based on the data?",
                criteria=[
                    "Weak — underperforming, declining, no institutional interest",
                    "Below average — flat or lagging the market",
                    "Average — in line with broader market",
                    "Above average — outperforming with some catalysts",
                    "Strong — leading sector with heavy flows and clear momentum",
                ],
            )
            questions[f"{sector}_rotation"] = Noul(
                instructions=f"Is money rotating INTO `{sector}` sector (vs rotating out)?",
            )

        answers = self._jev.evaluate(state=state, questions=questions)
        if answers is None:
            return None

        try:
            scored = []
            for sector in SECTORS:
                mom_raw = answers[f"{sector}_momentum"].score
                mom = mom_raw / 4.0 if mom_raw == mom_raw else 0.0  # NaN guard
                rot = answers[f"{sector}_rotation"].noul
                rot = rot if rot == rot else 0.0  # NaN guard
                composite = 0.6 * mom + 0.4 * rot
                scored.append({"name": sector, "momentum": mom, "rotation": rot,
                               "composite": composite})

            scored.sort(key=lambda s: s["composite"], reverse=True)

            sectors_out = []
            for i, s in enumerate(scored):
                if i < 3:
                    bias = "bullish"
                elif i >= len(scored) - 3:
                    bias = "bearish"
                else:
                    bias = "neutral"
                sectors_out.append({
                    "name": s["name"],
                    "intraday_bias": bias,
                    "theme": "sector rotation",
                    "catalyst": f"jev: momentum={s['momentum']:.2f}, rotation={s['rotation']:.2f}",
                })

            return {
                "sectors": sectors_out,
                "reasoning": f"jev: {len(SECTORS)} sectors scored, ranked by composite",
            }
        except Exception:
            log.warning("Jev sector answer parsing failed", exc_info=True)
            return None
```

```python
"""Live regime monitor: Jev-based regime check during market hours."""

from __future__ import annotations

import logging
from dataclasses import dataclass
from datetime import datetime
from typing import Any

from tradingbot.core.jev_client import JevClient, Choice, Noul

log = logging.getLogger(__name__)


@dataclass(frozen=True)
class RegimeCheckResult:
    changed: bool
    new_regime: str | None
    confidence: float


_NO_CHANGE = RegimeCheckResult(changed=False, new_regime=None, confidence=0.0)


class RegimeMonitor:
    """Check for intraday regime shifts via Jev every N seconds."""

    def __init__(self, jev_client: JevClient, check_interval_seconds: int = 300) -> None:
        self._jev = jev_client
        self._interval = check_interval_seconds
        self._last_check: datetime | None = None

    def should_check(self, now: datetime) -> bool:
        if self._last_check is None:
            return True
        return (now - self._last_check).total_seconds() >= self._interval

    def check(self, market_data: dict[str, Any], current_regime: str) -> RegimeCheckResult:
        if Choice is None or not self._jev.available:
            return _NO_CHANGE

        questions = {
            "regime_changed": Noul(
                instructions=f"Has the market regime changed from `{current_regime}`?",
                criteria={
                    "true": "Significant shift in market conditions since morning",
                    "false": "Conditions consistent with the morning regime",
                },
            ),
            "new_regime": Choice(
                instructions="What is the current market regime?",
                criteria={
                    "trending_up": "Broad uptrend",
                    "trending_down": "Broad downtrend",
                    "range_bound": "Sideways, no conviction",
                    "volatile": "High volatility, sharp swings",
                    "low_vol_squeeze": "Compressed volatility, breakout imminent",
                },
            ),
        }

        answers = self._jev.evaluate(state=market_data, questions=questions)
        self._last_check = datetime.now()

        if answers is None:
            return _NO_CHANGE

        try:
            changed_prob = answers["regime_changed"].noul
            new_regime = answers["new_regime"].choice
            confidence = answers["new_regime"].confidence

            if changed_prob > 0.7 and confidence > 0.5:
                log.warning(
                    "Regime shift detected: %s → %s (change_prob=%.2f, conf=%.2f)",
                    current_regime, new_regime, changed_prob, confidence,
                )
                return RegimeCheckResult(changed=True, new_regime=new_regime, confidence=confidence)

            return _NO_CHANGE
        except Exception:
            log.warning("Regime monitor answer parsing failed", exc_info=True)
            return _NO_CHANGE
```
