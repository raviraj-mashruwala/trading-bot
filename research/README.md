# research/

One-off backtesting and strategy-validation scripts. Not part of the
production pipeline (`tradingbot/`) and not invoked by it — these are
standalone analysis tools run manually to test trading hypotheses against
historical data before any strategy gets built into the live bot.

`output/` holds generated results (candidate lists, trade logs, CSVs). These
are scratch artifacts, not canonical data — they're regenerated by re-running
the corresponding script, not maintained by hand.

Do not write analysis output into `trade_plans/` — that directory is reserved
for real daily plans the live pipeline generates (`YYYY-MM-DD.json`), and
`PlanStore.load_latest()` / the `/api/plans` route only look for genuine
plan filenames, but keeping research output fully separate avoids confusion
either way.

## Scripts, roughly in the order they were used

- `analyze_plans_with_intraday.py` — replays historical trade plans against
  real intraday 1m/5m data to check if planned entries would have filled.
- `backtest_orb.py` / `backtest_orb_v2.py` — opening-range-breakout entry
  backtests (rejected — misses the move on gap-and-run days).
- `backtest_immediate_entry.py` / `backtest_immediate_entry_v2.py` —
  immediate-entry-at-open with live-computed stop loss (validated as the
  sound entry mechanism, candidate-selection signal still unproven at the
  time).
- `replay_tier1_history.py` / `fetch_replay_intraday.py` /
  `backtest_replay_holdout.py` — replays the real Tier1 deterministic
  screener across many historical days with a proper tuning/holdout split.
- `prepare_llm_dossiers.py` / `apply_llm_rubric_judgment.py` /
  `apply_llm_rubric_judgment_v2.py` — tests manually-reasoned stand-ins for
  the real LLM shortlist call (to avoid API spend) against the same
  historical candidates.
- `backtest_swing_momentum.py` / `backtest_swing_meanreversion.py` — swing
  (multi-day hold) breakout and mean-reversion hypotheses on the full
  7-year daily dataset.
- `refine_swing_short.py` — parameter grid search for the short-side
  mean-reversion swing hypothesis, restricted to F&O-eligible stocks (India
  doesn't allow overnight shorts in cash equity).

See the project design doc for the full narrative and conclusions from each
of these.
